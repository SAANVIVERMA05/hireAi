# 🚀 AI Recruitment & Resume Analyzer Platform

An AI-powered recruitment platform that helps recruiters efficiently manage hiring while enabling candidates to analyze resumes, apply for jobs, and prepare for interviews using AI-driven tools.

Built using the Lovable Stack with a modern scalable architecture.

---

# 🌟 Features

## 👨‍💼 Recruiter Features

* Recruiter Authentication (Sign Up / Login)
* Recruiter Dashboard
* Post & Manage Jobs
* View Applications
* View Candidate Profiles
* Resume & ATS Score Review
* AI Resume Matching
* Shortlist / Reject Candidates
* Application Status Tracking

### 📌 Job Posting Includes

* Job Title
* Job Description
* Required Skills
* Experience Required

### 📌 Application Status

* Applied
* Shortlisted
* Rejected
* Selected

---

## 👨‍🎓 Candidate Features

* Candidate Authentication
* Profile Creation & Management
* Upload Resume (PDF/DOC)
* Browse Jobs
* Apply for Jobs
* Track Application Status

## 📄 AI Resume Analyzer

Automatically analyze resumes using AI and NLP techniques.

### Features

* Skill Detection
* ATS Score Generation (0–100)
* Resume Improvement Suggestions
* Missing Keyword Detection

# ⚙️ Core Workflow

## Resume Analysis Workflow

```text
Resume Upload
      ↓
Text Extraction
      ↓
NLP Skill Detection
      ↓
ATS Score Calculation
      ↓
Resume Improvement Suggestions
```

---

## Recruitment Workflow

```text
Recruiter Posts Job
        ↓
Candidates Apply
        ↓
AI Resume Matching
        ↓
ATS Score Evaluation
        ↓
Shortlisting Process
```
